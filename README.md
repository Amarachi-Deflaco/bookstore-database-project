# Bookstore Database Project

## Overview
This project is a relational database designed to manage bookstore operations including books, customers, and sales.

## Tools Used
- SQL
- MySQL Workbench

## 📊 Features
- Designed database schema
- Created tables with primary and foreign keys
- Wrote SQL queries for analysis
- Managed relationships between entities
